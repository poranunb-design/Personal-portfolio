## 🎯 Purpose

Repository นี้จัดทำขึ้นเพื่อรวบรวมผลงานการเรียนรู้ แบบฝึกปฏิบัติ และใบรับรองที่เกี่ยวข้องกับระบบเครือข่ายคอมพิวเตอร์ เพื่อใช้เป็นแฟ้มสะสมผลงาน (Portfolio) สำหรับแสดงความรู้และทักษะที่ได้รับจากการศึกษาในรายวิชา


## 🛠️ Tools & Technologies

- **Cisco Packet Tracer** — ใช้จำลองและทดสอบระบบเครือข่าย
- **Network Configuration** — ฝึกกำหนดค่าอุปกรณ์เครือข่าย
- **Control Plane Policing (CoPP)** — ศึกษาการควบคุมทราฟฟิกที่ส่งไปยัง Control Plane ของอุปกรณ์เครือข่าย

## 🎯 Objectives

- เข้าใจหลักการออกแบบและจัดการระบบเครือข่าย
- สามารถจำลองและทดสอบเครือข่ายด้วย Cisco Packet Tracer
- พัฒนาทักษะการกำหนดค่าและแก้ไขปัญหาเครือข่าย
- เรียนรู้การประยุกต์ใช้แนวคิด Network Programmability ผ่านการลงมือปฏิบัติจริง
